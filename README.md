# Electron-Lark

 ![release-download-count](https://img.shields.io/github/downloads/Ericwyn/electron-lark/total.svg)

 ***下载地址: [Release](https://github.com/Ericwyn/electron-lark/releases)***


electron 版的飞书 Feishu (原 Lark)，对网页版本进行封装

相比起普通网页版，功能如下

- 独立的运行窗口，不容易误关闭
- 关闭程序时后台运行，隐藏到通知栏小图标，双击可重新打开界面
- 新消息提醒，状态栏小图标闪烁
- 解除浏览器限制，避免因浏览器版本不对而提示无法使用
- 在消息浮窗主动触发 Jev 分析，在气泡下选择 AI 推荐回复

## Jev 回复助手

打开「设置 → 功能设置 → Jev 助手」，填写 OpenRouter 的 Jev Decisions 完整地址（默认 `https://openrouter.ai/api/alpha/decisions`）、API Key 和 Jev 模型。Key 使用系统安全存储加密，留空保存会保留原 Key，也可勾选清除。

回复生成调用本地 Codex CLI，使用已有登录，无需另配 OpenAI API Key。先在终端完成 `codex login`；程序自动从 PATH、ChatGPT.app 或 Codex.app 查找可执行文件，也可填写绝对路径和可选模型。已验证 CLI `0.155.0-alpha.16`；旧版本不支持所需隔离参数时会提示运行失败，需要升级 CLI。

「Codex 思考强度」可跟随模型默认，或选择 none/minimal/low/medium/high/xhigh/max/ultra。具体级别取决于模型和 CLI，不支持时显示错误，不静默降级。单次生成最多等待 10 分钟；Skill 等待用户授权或补充信息时暂停计时。

在「本地 Skill」添加包含名称元数据的 `SKILL.md`，可编辑显示名称或移除配置（不删除本地文件）。点击分析先选择回复模式，以及一个 Skill 或「不使用 Skill」，点击「开始分析」才请求模型。不使用 Skill 时保持无工具的回复起草；使用 Skill 时通过本机 Codex app-server 显式加载该 Skill，复用 CLI 的工具配置和登录，允许执行其命令、读取参考资料及调用工具。命令/权限批准和工具补充信息在消息下处理，只对本次请求生效；不自动安装依赖或替用户发送回复。需要原生设备身份验证的工具须先在 Codex 中完成授权。

在消息气泡的浮窗工具栏点击「Jev 分析」。上下文为所选消息及同会话中此前最近 N 条**已加载**消息，N 可配置为 0–50，默认 10，所选消息另计。图片等无正文消息不向前补数，不加载更早记录，不做 OCR。总正文超过 60,000 字符时提示缩小范围。

Jev 先筛除明确无关的前序消息，保留不确定项，再批量判断可能意图、0–9 沟通风险、对方需求、建议动作、字面含义、实质回复条件、紧张是否解除，并保留缺失信息提示；Codex 根据判断、筛后上下文和回复模式生成三条不同策略的回复，由 Jev 按当前模式评估与排序。筛选失败会停止，不会把未筛选上下文交给 Codex。排序失败时仍保留候选，可单独重试排序。

可在 Jev 设置选择默认回复模式：专业、友善、简短、坚定、怼人、阴阳怪气、幽默。每次分析可临时选择；生成和排序共同遵循该模式。完成后切模式只使用同一批筛后上下文及 Skill 调查摘要改写，不重跑 Skill 命令或工具；切回已缓存模式不调用模型。改写失败或取消后可「返回已有分析」。修改配置或明确重新调查才建立新分析。

面板显示判断把握度；展开「完整判断与概率分布」查看各选项概率。候选显示本组推荐概率、事实依据、模式贴合和冲突升级风险；推荐概率不代表对方接受的成功率，不能跨模式直接比较。实质回复条件表示是否有足够事实作实质回应，不表示发送时机。低把握度会明确提示。Skill 调查摘要与来源可展开查看，并提供给 Jev 评估；它是模型整理的调查记录，不是独立审计结论。

群消息优先使用页面明确公开的 sender ID/name，无法识别时为每条未知消息保留独立身份，不将所有人合并成一个“对方”。目前真实群成员 DOM 的识别覆盖仍取决于飞书页面暴露的属性；不能据此推断群成员角色。选择自己发送的消息时，按自己的表达分析，不伪造对方立场。

直接引用的消息在候选范围内能以完整正文唯一匹配时，会保留其上下文；重复正文或截断引用不强制关联，也不会扩大配置的上下文范围。

点击候选只追加到当前输入框，保留原有草稿，确认后由你手动发送。切换会话、修改消息或配置会使旧结果失效；可取消进行中的分析。模型文本只作为纯文本展示。

分析区域随系统深浅色实时切换。当前会话最多保留 50 条分析结果；「收起」只隐藏面板，再点「查看分析」直接打开缓存，不重复调用模型。「重新调查并分析」会生成新结果并重新执行所选 Skill。模式结果也计入最多 50 条的内存缓存。切走会话或刷新后清空；取消/切换也会终止进行中的 Skill 进程组。

只有主动点击才会请求模型。候选上下文发送到配置的 Jev 服务；筛后上下文交给本地 Codex CLI，并由其登录的模型服务处理；生成的候选和相关调查摘要再交给 Jev 评估排序。聊天只通过 CLI 标准输入传递，临时结果在完成或取消后清理，不写入应用日志。

如提示无法读取配置，请检查「服务器设置」的启动页是否与实际登录后的飞书页面同源（包括租户域名），修改后重启。Key 鉴权/额度错误需检查 OpenRouter；CLI 登录错误需重新执行 `codex login`。系统安全存储不可用时不会明文保存 Key。

开发验证：`npm test` 运行 Node 单元测试、合成消息的完整模拟链路和 Electron 既有回归，不向真实会话发送消息。GUI 回归需桌面解锁。

## 安装方法 (二进制安装)
 - 请从 [Release](https://github.com/Ericwyn/electron-lark/releases) 页面直接下载及安装 （ubuntu 18.04 上测试通过）

## 安装方法 (从源码安装)

### 0. 安装 NodeJs
请先按照官网教程安装 NodeJs，确保以下命令可以成功运行

    node -v
    npm -v


### 1. 安装 Electron

参考 https://qii404.me/2019/07/10/electron.html

```
# 墙内的话安装过程中会下载失败，需要首先设置electron的源为淘宝源即可
npm config set ELECTRON_MIRROR http://npm.taobao.org/mirrors/electron/

# 全局安装 需要的话追加上 --registry='http://registry.npm.taobao.org' 使用淘宝npm源安装
sudo npm install electron -g --allow-root -unsafe-perm=true
# Windows使用下面语句 64位32位机器都是--win32
npm install electron -g --platform=win32

# 验证安装
electron -v
```



### 2.运行

工程目录下使用下面命令运行

```
electron .
```
