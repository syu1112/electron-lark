Jev 助手

在消息浮窗点击「Jev 分析」后才运行。候选回复点击后追加到输入框，由你确认发送。

所选消息另计；先从前序范围中剔除无关消息，不向前补数。

可用强度取决于所选模型和本机 CLI；不支持的组合会显示错误，不会静默替换。

本地 Skill

点击 Jev 分析时可选择一个 Skill。所选 Skill 通过本地 Codex 完整执行，复用 CLI 已配置的命令、工具和登录；需要授权或补充信息时在分析面板处理。回复仍由你确认发送。

使用本机 Codex 已有登录，无需另配 OpenAI API Key。候选上下文交给 Jev 筛选，筛后上下文交给 Codex 生成回复。
